# Form distribution

This section covers the ways forms can be delivered to end users for completion.

It includes:

* [sharing forms by link](aidbox-ui-builder-alpha/form-sharing.md)
* [sending forms to patients](aidbox-ui-builder-alpha/form-sending.md)
* [embedding forms and packages](aidbox-ui-builder-alpha/embedding.md) in an application
* [printing forms](aidbox-ui-builder-alpha/printing-forms/README.md), including [Liquid print templates](aidbox-ui-builder-alpha/printing-forms/liquid-templates.md)
* [working with forms offline](aidbox-ui-builder-alpha/offline-forms.md)

[Form packages](plan-definitions.md) can be shared through one link or sent through the email workflow. Each link belongs to a package run; the recipient completes its enabled forms and submits them together. See [sharing a package](aidbox-ui-builder-alpha/form-sharing.md#sharing-a-plan-definition) and [sending a package](aidbox-ui-builder-alpha/form-sending.md#sending-a-plan-definition).
